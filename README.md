# 城市地下综合管廊运行维护管理平台

面向管廊主体台账、入廊管线登记、廊内环境监测、通风排水消防、结构沉降与渗漏处置、巡检检修与隐患整改、入廊作业审批和运维值班的一体化城市地下综合管廊运行维护管理工作台。

这是一个**纯前端**管理平台：Vue 3 + Vite + TypeScript，仓库里没有后端服务。业务数据由
`frontend/src/data/` 下的本地数据层提供：首次打开用示例数据播种，之后的登记、筛选与状态流转
结果都持久化在浏览器 `localStorage` 里，刷新或重开浏览器都还在。dev server 已关掉自动打开页面，
启动后按终端打印的地址手工打开。

## 目录结构

```text
.
├── frontend/                 Vue 3 + Vite + TypeScript 前端（唯一运行单元）
│   ├── src/views/            每个业务模块一个页面
│   ├── src/api/local-service.ts   本地数据服务：列表、筛选、动作流转、导出
│   ├── src/data/             模块元数据 / 示例数据 / localStorage 持久化
│   ├── src/stores/           会话与筛选状态
│   └── vite.config.ts        dev server 配置（open: false，无 /api 代理）
├── .gitignore
└── docker-compose.yml
```

## 启动

```bash
cd frontend
npm install
npm run dev
```

前端默认监听 `http://127.0.0.1:5173/`，dev server 不会自动打开浏览器，需要自己访问。

生产构建：

```bash
cd frontend
npm run build
```

## 约定

- 每个模块的页面在 `frontend/src/views/<模块>/index.vue`，页面只负责渲染，读写统一走
  `frontend/src/api/local-service.ts`。
- 字段、状态、动作与流转目标集中在 `frontend/src/data/modules.ts`；示例数据在
  `frontend/src/data/seed.ts`。
- 状态流转只允许在 `local-service.ts` 里改，页面组件不做业务判断。
- 想回到初始数据：清掉浏览器里 `urban-utility-tunnel:entries` 这一项，或调用 `resetModule(模块)`。

## 排水泵坑水位空态与异常仲裁（`frontend/src/drainage/`）

排水泵坑在通用 CRUD 之外单独建域，专门解决「取不到水位被当成 0 米、页面还显示正常」的问题。

- `types.ts`：读数带 `ok / missing / invalid` 显式状态，缺数为 `null`，与数字 `0` 严格区分。
- `rules.ts`：解析、越界、两路仲裁、状态判定、台账对账、存量「断线写成 0」识别，均为纯函数。
- `store.ts`：持久化（`urban-utility-tunnel:drainage-domain:v1`）、重试取数、现场录入、
  现场校准、按月迁移；每次写入都在一个提交事务内对账待查台账并把液位计镜像进设备台账
  （`id = 9000 + 泵坑 id`），清单、待查台账、设备台账三处读数同源，不各算各的。
- 种子数据 `seed.ts` 覆盖：断线 3 天、两路冲突、配置越界、读数越界、真实 0、通道抖动，
  以及 2026-04 ~ 2026-07 四个月待迁移存量（疑似断线置零 / 真零保留 / 缺项回填 / 两路皆空）。

判定规则（页面「仲裁 / 识别规则」可展开查看）：

1. **空值 ≠ 0**：缺数 / 非法一律显示「暂无」并交代原因，不参与启泵判定；真实 0 正常显示 `0.00 m`。
2. **重试升级**：重试每点一次重新取数；连续 3 次失败才提示去现场核，之前只给重试入口；恢复或现场录入后计数清零。
3. **越界单独提示**：启泵水位 ≥ 集水坑容积为「配置越界」；水位超出 `0~容积` 为「读数越界」，与缺态互不混同。
4. **两路仲裁**：现场实测与遥测相差 > 0.05m 时以现场实测为准统一，遥测按实测回算偏差，液位计列待校准；
   现场值越界直接拒收。依据：液位是现场物理量，人工读数贴近真值，遥测受断线 / 漂移影响。
5. **同坑去重**：同一泵坑同类未闭环异常在待查台账只记一次。
6. **早年断线 0 识别（三条同时命中才置空，从严）**：①该 0 仅来自遥测、无同日现场 0 佐证；
   ②前后相邻读数均非 0 且双向跳变 ≥ 0.5m（V 形尖底）；③同期通道有故障 / 超时日志。
   命中置空并列待校准；有现场 0 佐证的真 0 保留并注明出处。
7. **存量迁移**：按数据月份分批、由早到晚执行；缺项按上次巡检日期的现场实测回填、备注写出处；
   巡检也未量的保持空态。顶栏可切换归属单位，跨单位代提交 / 重试 / 校准 / 迁移一律挡回。
